# Языки интерфейса и сервера

Pult работает на русском, английском и китайском (упрощённое письмо). Русский — исходный язык.

## Интерфейс

- Все строки интерфейса берутся по ключам из `web/src/i18n/ru.json`, `en.json` и `zh.json`. Строка прямо в разметке не проходит
  lint (`no-restricted-syntax`).
- Порядок выбора языка:
  1. явный выбор в меню учётной записи (хранится в этом браузере);
  2. иначе язык учётки (`users.locale`);
  3. до входа — язык браузера (`navigator.languages`), если он из трёх;
  4. иначе русский.
- На экране входа и в мастере установки есть свой выбор языка; он запоминается в этом браузере.
- При смене языка в меню он сохраняется в учётке (`PUT /api/me/locale`). На этом языке пользователю приходят письма.
- Интерфейс ставит cookie `pult_lang`, по ней сервер узнаёт язык запроса.

## Сервер

- Язык запроса определяет middleware `pult_core::l10n::scope`:
  1. cookie `pult_lang`;
  2. иначе `Accept-Language`;
  3. иначе русский.
- На языке запроса отдаются:
  - сообщения об ошибках;
  - описания прав;
  - подписи отчётов и листы выгрузки XLSX/CSV;
  - стартовые коды закрытия;
  - служебные слова в журнале аудита (только при показе; выгрузка журнала остаётся как записано).
- Перевод — каталоги `crates/pult-core/src/l10n/en.tsv` и `zh.tsv`, по строке `русский<TAB>перевод`:
  - `\n` обозначает перевод строки;
  - `{имя}` и `{}` — подстановки из `format!`;
  - строки без табуляции — пояснения.
- Тест `crates/pult-core/tests/l10n_coverage.rs` находит в исходниках каждую русскую строку, которую видит пользователь,
  и падает, если её нет в каталоге. Так же он падает на устаревшие записи каталога.
  - В `zh.tsv` должны быть все строки `en.tsv` и русские половины `l("…", "…")` из писем
    (`pult-helpdesk/src/notify.rs`): английская половина стоит в коде, китайская берётся из каталога.
  - Новая строка ошибки или подписи — добавьте её перевод в каталог.
  - Строки журнала (`tracing`), CLI и `expect`/`assert` не переводятся.
- Фоновые задачи языка запроса не знают и выбирают язык сами:
  - письма — по языку получателя (`users.locale`);
  - текст автоматического решения заявки — по языку заявителя;
  - еженедельный отчёт и письма суперадминистраторам — на языке установки.
- Язык установки задаётся в разделе «Администрирование → Система» (`/api/admin/locale`). Его получают новые учётки.
- Данные, введённые людьми, не переводятся: названия категорий, статьи, комментарии, свои коды закрытия.
